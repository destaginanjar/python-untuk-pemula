# Python untuk Pemula

Repository ini berisi hasil praktikum pembelajaran dasar Python berdasarkan materi Python untuk Pemula dari Santrikoding.

## Tujuan Praktikum

- Memahami dasar-dasar bahasa pemrograman Python.
- Mempraktikkan penggunaan variabel, tipe data, operator, dan kondisi.
- Memahami perulangan, fungsi, class, dan object.
- Memahami penggunaan PIP dan Virtual Environment.
- Menggunakan Git dan GitHub untuk mengelola riwayat perubahan kode.

## Materi yang Dipelajari

1. Pengenalan dan Instalasi Python
2. Variabel dan Tipe Data
3. Operator pada Python
4. Kondisi If Else pada Python
5. Perulangan pada Python
6. Lists dan Dictionaries
7. Function
8. Class dan Object
9. PIP dan Virtual Environments
10. Konfigurasi Environment/IDE
11. README.md dan Requirements.txt

## Teknologi yang Digunakan

- Python 3.14.10
- PIP
- Virtual Environment (venv)
- Colorama
- Git dan GitHub
- Visual Studio Code

## Cara Menjalankan Project

1. Clone repository:

   ```bash
   git clone https://github.com/destaginanjar/python-untuk-pemula.git
   ```

2. Masuk ke folder project:

   ```bash
   cd python-untuk-pemula
   ```

3. Buat Virtual Environment:

   ```bash
   python -m venv venv
   ```

4. Aktifkan Virtual Environment di Windows PowerShell:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Instal library:

   ```bash
   python -m pip install -r requirements.txt
   ```

6. Jalankan salah satu program, contohnya:

   ```bash
   python pengenalan_python.py
   ```
